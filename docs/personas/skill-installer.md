# Skill installer

**Surfaces:** skills
**Reader:** an engineer adding the skill to a repository

## Who they are

28, platform engineer, installs agent skills for a team of five. Pins versions, reads what a skill will do before adding it, and keeps a lockfile because a teammate once got a different version than they did.

## The job they came to do

"Add this skill at a version I can pin, and know it works with the release I have."

## The one thing that makes them quit

Two different install commands in two places, or a skill that never says which CLI version it expects.
