# ProjectionLab user with Claude Code on the side

**Surfaces:** site, skills
**Reader:** a developer who already runs a retirement plan, and already pays for an agent

## Who they are

36, writes software for a living, and keeps a ProjectionLab plan whose simulation they rerun whenever the market moves. Pays for a Claude Code subscription and hands it the boring half of every task, so a tool that needs a dashboard is a tool they will not open twice. Has an accountant for the filing and no patience for one here.

## The job they came to do

"Get the answer my plan already gives me, from a conversation with my agent, and see why the number differs."

## The one thing that makes them quit

An install that is not one command their agent can run, a skill step Claude Code does not have, or a product that can record money but cannot project it: then the plan stays in the browser and the tool is gone.
