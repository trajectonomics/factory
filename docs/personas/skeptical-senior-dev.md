# Skeptical senior developer

**Surfaces:** site, core
**Reader:** a developer deciding whether to spend ten minutes

## Who they are

38, twelve years in, evaluates libraries at 11pm by reading the npm page and the README. Has two stars' worth of patience for a project with no track record, and a strong prior that anything with a landing page is marketing with no code behind it.

## The job they came to do

"Decide in three minutes whether this library is safer than the one I already use."

## The one thing that makes them quit

A blank npm page, no API list, no version policy, or a promise on the homepage that the docs never teach.
